# Code of Conduct

## What this is

This project is one person's work, published so other people can use it and improve it. The
conduct expected here is short enough to read in full, which is the point — a code nobody
reads is a code nobody follows.

It is adapted from the [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1. Where the wording differs, it is because this is a small project with one
maintainer and pretending otherwise would be dishonest about how a report actually gets
handled.

## The standard

Everyone taking part in this project — issues, pull requests, discussions, code review — is
expected to make it a place where people are not harassed.

**Things that are expected:**

- Taking somebody at their word about what they experienced, including when the bug makes no
  sense to you yet.
- Disagreeing about the work. Strong technical disagreement is welcome and is most of what
  happens here. Say the design is wrong and say why.
- Accepting a no. Not every idea fits, and a declined pull request is a judgement about the
  change, not about you.

**Things that are not:**

- Sexualised language or imagery, and unwelcome sexual attention of any kind.
- Insults, personal attacks, and attacks on somebody's background, politics or identity.
  Criticising the code is the job; criticising the person is not.
- Harassment in public or private, including following somebody from here to somewhere else
  to continue it.
- Publishing somebody's private information — a real name they do not use here, an address,
  a workplace — without their explicit permission. This cuts both ways: **a screenshot or a
  log attached to an issue is your own filesystem**, so check it for other people's names
  before you post it.
- Sustained disruption: reopening a settled decision in every thread, or demanding free
  work and then arguing about the refusal.

Technical criticism, however blunt, is not harassment. "This is wrong and here is why" is
the normal register of this repository. "You are an idiot" is not, and the difference is not
subtle.

## Scope

This applies in every space this project uses — the repository, its issues, its pull
requests, its discussions, its releases — and to anywhere somebody is representing the
project in public. It also applies to conduct outside those spaces that is directed at
someone *because* of their part in this project.

## Reporting

**Email <trescariasa2007@gmail.com>**, with `[filet conduct]` in the subject. It reaches the
maintainer and nobody else. Say what happened, where, and roughly when — a link to the thread
is enough if it happened here.

If you would rather not send an email, [open a private security
advisory](https://github.com/uukjtisa/filet/security/advisories/new) on this repository
instead. It is the only other private channel GitHub gives a maintainer: visible to them, not
to the person being reported, and not published. Put `conduct` in the title.

If the person you need to report is the maintainer, or you would rather not involve this
project at all, [GitHub's own abuse
reporting](https://github.com/contact/report-abuse) goes to GitHub Support and is independent
of it entirely. Use it without hesitating — being the only maintainer is exactly why that
route needs saying out loud.

**What happens then.** One person reads it, and that person has a degree to finish, so a
reply can take days. Every report gets a reply. What was reported stays private; reporters
are not named to the person reported. If a report concerns the maintainer's own conduct, it
goes to GitHub Support and not to a committee that does not exist.

## Consequences

In rough order, and the maintainer decides which applies:

1. **A private note** saying what was wrong and why, with what is expected instead.
2. **A warning**, with no interaction with the people involved — including unsolicited
   contact with whoever reported it — for a stated period. Breaking it escalates.
3. **A temporary ban** from the project's spaces.
4. **A permanent ban**, for sustained harassment, or for aggression toward or disparagement
   of a group of people.

A ban applies to the project's spaces. Nobody's right to fork this code is affected by any
of it — it is GPL-3.0, and that is not a privilege to be withdrawn.
