Round 5 — 2026-09-13

  • The split divider drags. Grab it to resize, double-click to reset to 50/50, and the fraction persists. It works in both orientations and is clamped so neither pane can go under 132 logical px — below that a pane stops being a pane. The maths uses fractions of the body rect, which is scale-independent, so it behaves identically in every scaled device frame.
  • The grip is always faintly visible (32%), not hover-only. A drag handle nobody can see is not a drag handle — and on touch there is no hover to reveal it.
  • About page, from Trawl's AboutPage.kt, restyled to Slate. The Signature Banner keeps Trawl's contract exactly: radius 22, diagonal surfaceHigh → container → surface gradient, 1px glass border, and the mark as a 158px watermark rotated -12° at 7% opacity, bleeding off the bottom-right so the panel reads as printed rather than assembled. The name carries the glare sweep — 2.6 s streak, 6.4 s rest, 9 s cycle, band at 42% of the name — and hovering it speeds the cycle up. The rule under it draws once on arrival (1100 ms, 120 ms delay), not on every glare loop; that was a bug worth not repeating.
  • Sections follow Trawl's shape: Project (source · licence · Trawl) → Built on credit card with per-dependency licences → Version. Filet is greenfield, so "Built on" credits the dependency stack rather than an upstream fork.

Round 4 — 2026-09-13

  • Search is per pane, not global. One search field in the top bar was ambiguous the moment a second pane or a second tab existed — it never said what it was searching. The field is gone from the bar; every pane header now carries its own ⌕. A pane is the thing that has a location, so a pane is the thing that owns a search. Two panes ⇒ two independent searches, each showing its own hit count; every tab keeps its own.
  • Scope is explicit, not guessed: This folder · Subfolders · Whole device · Provenance. The second ambiguity after "which pane" is "how far", and it should never be implicit.
  • The pane header is now visible at every width — it carries the search, so it can no longer be the first thing dropped on a phone.
  • SEARCH.md written — the full index model: bundled SQLite + FTS5 trigram, parent_id tree, NIO/JNI crawl, and the four-layer freshness stack. Headline rule: the index is a candidate generator, the filesystem is the truth — nothing is painted without a stat confirming it, so a dead file cannot reach the screen.

Round 3 — 2026-09-11 / 13

  • The slider left the toolbar. It crowded the bar and was unreadable on a phone. It now lives in a View popover behind one ⊞ button — slider, live step name, tick marks, and Sort (Name / Date / Size) in the same panel. Bar is back to: menu · path · search · view · split · more.
  • The whole view scales, not just the icon. Each step drives one variable set — --ic icon, --fs name, --fsm metadata, --fsc chips, --rowh row height, --tile tile width — so text, chips and icons grow together and the change animates.
  • The Home overview scales too, on its own damped curve (--ich / --fsh / --rowhh / --tileh). Home is always a list, so it must not follow the grid's jump to a 56px icon. Storage cards, tracked-download rows and timestamps all move with it.
  • Split is LENGTHWISE at every width — two narrow columns on a phone, the MT Manager layout, not stacked halves. Stacked is still available as an explicit third state on the split button.
  • Each pane is its own CSS container. A 180dp pane now lays its rows out like a 180dp screen: it sheds the date column at 330px, the size column and chips at 180px, and below 270px it overrides the slider entirely — six view steps need room a narrow pane does not have.
  • Narrow-pane fixes found by screenshot: home rows put the timestamp on its own line instead of competing with the filename; drive cards stack; tile labels break at . and - via <wbr> instead of snapping classes.dex into classes.de / x.
  • Folder tiles no longer print a bare — where a size would be.

Round 2 — 2026-09-10

  • Tabs. Explorer-style, persisted to localStorage (stand-in for the real config). New tab always opens the Home overview. Pinned shortcuts open as a new tab.
  • Home overview. Storage with capacity bars, then Recent, New downloads and Recently edited — the last two fed by tracked folders (Download is tracked by default), which is the same provenance/watcher machinery from PLAN §5.1, surfaced as a landing page.
  • View slider. Six steps: compact list → list → comfortable (2-line) → small / medium / large grid. Explorer's slider, one control.
  • Split is manual now, not just automatic. The panes button cycles single → side-by-side → stacked, at any width. Compact widths force side-by-side to stack, because two 180dp panes are useless.
  • Drag & drop works — drag a row onto a folder row or the other pane. Drop targets pulse, a ghost follows the cursor, and the toast reports the move.
  • Double-click opens with the registered default. No default ⇒ the chooser sheet, listing real activity names (…/.MusicActivity) with Just once / Always. Choosing Always writes the handler registry (PLAN L2) and the next double-click skips the sheet.
  • Editable path bar. Click it → the breadcrumb becomes the raw path, selected. Type, Enter navigates, Esc cancels. The copy button copies the path.
  • The Trawl switcher. ☰ pushes the whole app card away — translateX(50%) scale(.78), radius 26, 500ms on cubic-bezier(.5,.05,.15,1), menu rows in from -30px at 460ms / 50ms stagger / 60ms first delay on cubic-bezier(.2,.85,.3,1). Values read straight out of TrawlSwitcher.kt, not eyeballed. No 3D rotation — upstream rejected it and the comment says why. Tap the shrunken card to come back.
  • Motion pass. Rows stagger in, icons scale on hover, tiles lift, buttons dip on press, the + rotates, capacity bars fill, sheets slide, drop targets pulse. All of it dies under prefers-reduced-motion, per TEMPLATE.md rule 2.
