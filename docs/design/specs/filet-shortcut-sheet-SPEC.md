## 3. Behaviour rules

- **Sources and their order** (mock L905): a file with a picture: Picture, File type, Emblem, Drawing, Filet. A file without one: File type, Emblem, Drawing, Filet. A folder: Folder, Emblem, Drawing, Filet. A tab, action or script: Drawing, Emblem, Filet. The first is the default.
- **Default per subject** (mock L917): emblem `document` for a file, `star` otherwise; colour `steel` (Filet's colour); drawing = the subject's own, or Internal storage for a folder, Documents for a file; picture Fill; folder Same.
- **Same as the folder edits the folder** (mock L1039): a change made under Same is applied to the folder in Filet on Add, as Change icon would. Its own copies the folder's look once and never touches the folder.
- **Use a photo from inside** shows only for a folder with a picture in it (mock L1042).
- **Drawing caption** (mock L1050): `Every tab and action drawing. This one is its own.` when the subject's own is chosen, else `<Label>'s drawing.`
- **Name**: up to 40 characters; Add and Save are off while it is blank (mock L1070). The preview's name follows the field live.
- **Tapping the preview** brings the Icon section into view (mock L1223).
- **Opened from**: a file's menu, a row's hold or a tab's long-press: no Opens row. The Shortcuts tab: Opens row with Change, which goes to the chooser. One already pinned: Opens row without Change, title Shortcut, Remove/Cancel/Save.
- **Add** asks the launcher with the chosen name, opener and icon; the record carries the icon string through the launcher's answer. **Save** updates the pinned shortcut's name and icon in place.
- **Nothing on a black square**: a picture fills the launcher's shape or sits whole in its safe middle; drawn sources are drawn on a clear square.

## 4. Where the app cannot do what the mock shows

- **Remove**: Android gives an app no way to take a pinned icon off the home screen. Remove turns the shortcut off (the launcher greys it and says it was removed in Filet) and drops it from the list; the message says to drag it off. Nearest faithful.
- **Choose a file or folder**: Filet's picker takes one file, or the folder being stood in, never either in one pick. The chooser has two rows, Choose a file and Choose a folder.
- **Picture** is offered for any file Filet has a picture of (photos, video frames, app icons, covers), not only photos and videos as the mock's samples are. A picture with see-through edges (an app icon) starts Framed, so it keeps its shape; an opaque one starts Fill, as the mock does.
- **Cancel's message** in the mock (`Cancelled: nothing added`) narrates the mock; the app closes the sheet without a message, as every other sheet does.
- **Start sharing's line**: the mock's `Starts sharing; says Stop sharing while a share runs.` is true of the held icon's menu, not of a placed icon, which cannot change its name by itself. Start sharing says `Starts sharing and shows the code.`; Stop sharing, which the Shortcuts tab also offers, says `Stops sharing without opening the tab.`
- **Folder size on the launcher**: a folder's home-screen drawing keeps the 0.56 box it already ships with (its corners stay inside the 66 circle every launcher keeps); the mock places it at 64 of 108. File types, emblems and the plain disc are placed as the mock places them.
- **The side panel's switches** (Build, Theme, Launcher shape, Wallpaper, Layout, Minimalist) are for reviewing; the app uses this build's colours and theme, a circle preview on the dark patch, and the icon beside the name.
