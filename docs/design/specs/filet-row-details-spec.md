## Risks to settle while building, not by eye

- **Sample folders have no contents**, so the folder art would draw its empty state, not the folder with pictures
  the mock shows. The preview has to give the art its contents (the sample entries' children) through the same
  path a real folder uses. If that path can't take sample data, say so before substituting.
- **The folder total pulses while unsettled.** The preview must hand the row a settled total, or the sample
  breathes forever. `LocalFolderBytes` gets a fixed stand-in for the preview.
- **Thumbnails**: sample files must not try to load thumbnails from paths that don't exist.
