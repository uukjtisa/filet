## 3. Motion — the first thing lost in translation

| Animation | Duration | Delay | Easing | Fill / repeat | Source |
|---|---|---|---|---|---|
| Sheen sweep | 2600 ms streak in a 9000 ms cycle | — | linear | infinite restart | mock:129 |
| Touch sheen | 1100 ms | — | ease-out | once, then hands back to the loop | mock:140 |
| Flourish draw | 1100 ms | 120 ms | `cubic-bezier(0,0,.2,1)` → **OutCubic** | `both`, **once on arrival only** | mock:148 |

`.18s ease-out` must arrive as an 180 ms OutCubic, not "a quick fade". The flourish is
**not** tied to the sheen loop — that was a Trawl bug worth not repeating, and the existing
Filet code already avoids it.

## 4. Behaviour rules, including the invisible ones

1. **Reduced motion**: no sweep, no draw. The flourish renders fully drawn and the name
   renders in solid `onSurface` with no gradient — never invisible. mock:201
2. **The sheen paints glyphs only, as the text's own brush** — `TextStyle(brush = …)`, a
   linear gradient that is the base colour everywhere except a narrow travelling band.

   **An earlier version of this spec said to use `BlendMode.SrcAtop` inside
   `drawWithContent`, and that was wrong on the device.** The claim was that SrcAtop
   composites only where the destination is opaque, so it would land on the glyphs alone. It
   is wrong about what the destination IS: inside `drawWithContent` the canvas is the one
   the card is already painted into, not an isolated layer holding only the glyphs — so the
   whole gradient panel behind them counts as opaque, and the result is a bright rectangle
   with a hard vertical edge across part of the word. Which is the exact defect the redesign
   was meant to fix, faithfully reproduced in Kotlin.

   `CompositingStrategy.Offscreen` also fixes it, at the cost of a layer per frame. The
   brush does not need fixing: there is no second shape, so a rectangle cannot occur.
3. **Sheen band is sized to the measured name**, not to the card. Capture the width in
   `onTextLayout`. The current code uses 42% of the card, which is the thing being replaced.
4. **Touching the name fires the sweep** and control returns to the ambient clock only after
   the streak has finished leaving — taking it back mid-streak cuts the highlight off
   mid-glyph.
5. **The support card renders nothing when `SupportLink.URL` is blank.** Unchanged, and it is
   what stops a dead link ever shipping.
6. **Support card is first in Project, above Source.** mock:306
7. **Every colour is a theme token.** Ember and light must follow with no extra work.
