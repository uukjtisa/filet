Link files

A small file, .ft_lnk, that opens a folder, a file, a saved search or a place on a network drive inside Filet.

Screen

Round 1. A link draws as what it points at - the folder's look, its item count and date - with a small arrow on the icon and a link tag. Tap opens the target in place; back returns to the folder the link is in.

Made from the hold menu (Link file, beside Shortcut) and from New file. It is put in one of the target's own folders, top of storage first, so by default it points only inside the folder it sits in and keeps working when that folder is moved, network drives included. Anywhere is the other choice, with a line saying it can break.

Broken: faded, a missing tag, and a menu with Find it, Point elsewhere and Delete. Find it looks the name up in the index and rewrites the link when it is found.
