Decided (approved 2026-11-15)

  • B, built. The bar keeps name, Save and More; More opens on "Show as" with every mode the file has (Page, Code, Hex). A stays here for comparison.
  • The page is live. Type in Code and the page is drawn from what is typed; Save writes it, and going back to Page shows the saved text. Try it above: Code, type, the check mark, then Page.
  • Which files get a Page mode. HTML and Markdown today. CSV as a table and JSON as a tree are the next obvious ones; each is a mode, not a new screen.
  • What opens first. Page for HTML and Markdown (reading is the common case), Code for everything else.
  • Open with keeps the separate entries. "HTML viewer" and "Code editor" stay listed so a default can still be set to either; both open this one screen, in that mode.
  • Unsaved edits across modes. Switching to Page renders the unsaved text; leaving still asks Save / Discard / Keep editing through the shared leave guard.
