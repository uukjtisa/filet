Today it's two flat lists: the bar with up/down/remove arrows, then 19 things in the order the code declares them, with no icons. The proposal keeps the same section and order rules (the last item can't be removed; past six the bar scrolls sideways) and changes four things: an icon on every row, a grip to drag, "Not on the bar" grouped like the side bar, and a preview of the bar at the top of the section.

TalkBack: holding a row gives Move up and Move down as actions, so the order can still be changed without dragging. The grip is the only place a drag starts, so scrolling the list never picks a row up by accident.

2 · The hold menu (holding Filet's icon on the home screen)

Today the four are fixed: Search, Bookmarks, Start/Stop sharing, Index now. The proposal adds a Hold menu section to the Shortcuts tab where you pick the four from every tab plus the actions. Four is a hard cap because launchers drop anything past it, and which ones they drop varies by launcher. The sharing entry still flips between Start and Stop on its own.
