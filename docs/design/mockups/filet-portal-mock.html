  • Encryption, not obfuscation: AES-256-GCM in 64 KB sealed segments, a fresh key per send, because Filet's code is public and anything obfuscated can be undone by reading it.
  • The manifest (names, sizes, which host holds which part) is encrypted too, so a host sees only random names and ciphertext.
  • Network drives stream straight from the drive into the upload, with no copy in the phone's cache; a folder goes as a zip made in the cache first, because a host needs the size before the upload starts.
  • A host that refuses an upload hands that part to the next host on; a part no host takes is marked failed with Send again.
