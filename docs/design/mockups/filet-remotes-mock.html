What changes

  • Rows. Each saved share is drawn like a folder in a file list at the Comfortable step: a 34dp tile, the name at 14sp Medium, and one 11sp meta line. The meta line reads kind · unencrypted (FTP or WebDAV without TLS) · last-known state · address. The state is this session's test (green reachable, red failed, amber dialling), else when it was last opened; a share never opened shows no state at all. A failed test keeps its one-sentence reason under the row.
  • Hold menu. The same panel as the mini player's Background glow and the viewers' More. It opens at the held row, below it, or above when there is no room. It holds Open, Test, Edit, Duplicate, Select, the index switch, and Forget in red.
  • Selection. Tapping a row's tile, or choosing Select in the hold menu, starts a selection. While selecting, a tap toggles a row. The pill is the file list's own: the count, Clear, a divider, then captioned buttons (Open, Test, Edit, Duplicate, Forget) and All. Open, Edit and Duplicate work on one share; with two picked they grey out and say why when pressed. Back clears the selection.
  • Unchanged. Found on this network, Add a place, Hosting and the Root card.
