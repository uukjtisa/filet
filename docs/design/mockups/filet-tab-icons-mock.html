How they're drawn

  • Only what Android icons can draw: shapes, solid and gradient fills, transparency. No blur and no masks, so the build is the same drawing as this page.
  • Each icon sits on the standard 108-unit adaptive canvas and keeps its ink inside the 66-unit circle, the shape every launcher mask contains. Turn on Safe circle to see it.
  • Themed mode (Android 13+) uses the same line glyph the tab has inside Filet, so a themed home screen still reads the same as the app.
  • Pinned icons follow app updates. If one changes later, the copies already on a home screen change with it.
