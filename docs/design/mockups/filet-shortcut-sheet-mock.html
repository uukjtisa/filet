One "Add to home screen" for everything

Files, folders, tabs, actions and scripts all go through this one sheet, whether it's opened from a file's menu or from the Shortcuts tab. Every kind gets a name and an icon you can change. Files also keep their "Opens with" row. Everything below is clickable, and your picks are saved in this browser.

ON THE HOME SCREEN
YOUR NOTES
Round 1 · 2026-11-14. First draft. The Today view reproduces the two sheets that exist now, warts included. A file gets an opener but never sees its icon. A folder gets an "Opens with" row with a single Default chip in it. A tab, an action or a script shows its icon but you can't change it. And the icon a file ends up with on the home screen is its thumbnail on a black square, or plain Filet when it has no thumbnail. The New view is a single sheet that does all of it:
  • the home-screen icon over its cut name, on a patch of wallpaper so you can see it's transparent;
  • the name field;
  • Opens with, for files only;
  • an Icon row: Picture, File type, Folder, Emblem, Drawing, Filet.
Folder and Emblem use the same emblem grid and colours as Change icon. Drawing gives you every tab and action drawing. Every icon is drawn in your build's colours, so in Filet Debug it turns amber, same as the tab shortcuts already do. Opened from the Shortcuts tab, the sheet starts with an "Opens" row you can change. Opened on a shortcut you already pinned, it becomes Edit, with Remove.
