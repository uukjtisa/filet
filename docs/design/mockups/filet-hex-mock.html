Hex editor: fast rows, a caret lit in both columns, full-width rows that scroll sideways

Left is today: sixteen separate cells per row squeezed into the screen, a dialogue per byte, no caret. Right is the proposal. Tap a byte to put the caret there, and it lights in the hex column and the text column together. Shift-click, or drag on the phone, to select a run; the selection is mirrored too. Scroll the right panel sideways. Press E to edit the byte at the caret, then use Undo and Redo.

What changes

  • Speed. Each row is one line of text with a fixed height, formatted once and cached. Today every row is sixteen separate cells, each with its own tap target, and every visible row is redrawn whenever one byte changes.
  • Live highlighting. The byte at the caret is lit in both columns, and a selection lights the same run in both. A status line under the rows gives the caret's offset and value, or the selection's length.
  • Full width. Rows keep their whole width (offset, 16 bytes, text) and the view scrolls sideways. Nothing is squeezed to fit.
  • Editing. Tapping the byte already at the caret opens the byte dialogue as today, which keeps each change a deliberate decision. Undo and Redo walk the changes, using the same history as the text editor. Save is the editors' shared Save: Replace original, or Save as new.
  • Bar. Undo, Redo, Save, ⋮. Open as text and Properties live in ⋮ (Code mode and Details).
